ScamLens is a cybersecurity analysis platform designed to address the limitations of conventional phishing scanners through three core innovations built in pure Java Spring Boot.

Groundbreaking Architecture

Three Major Innovations of ScamLens

Engineered to eliminate false alarms and deliver explainable, audit-grade scam analysis.

Innovation 1
Context-Aware Rule-Based Scam Detection
  • Semantic Intent Analysis: Analyzes the meaning and intent of messages rather than relying only on suspicious keywords.
  • Differentiates Warnings vs Requests: Distinguishes legitimate institutional security warnings (e.g. "Bank will never ask for OTP") from actual hostile scam attacks.
  • Advanced Context Primitives: Incorporates negation detection, request-intent recognition, and suspicious-action identification.
Innovation 2
Explainable Multi-Indicator Risk Assessment
  • Multi-Indicator Evaluation: Evaluates multiple suspicious indicators using a weighted risk-scoring mechanism.
  • Standardized Risk Scale: Generates a calibrated risk score strictly between 0 and 100 with category capping.
  • Transparent Explanations: Provides full explanations for detected threats, suspicious phrases, and assigned risk levels.
Innovation 3
Integrated User-Centric Cybersecurity Platform
  • Unified Analysis: Combines message content analysis and suspicious URL analysis in a single application.
  • ScamLens Compare: Provides dual-message comparison to contrast risk profiles and semantic structures side by side.
  • Personalized Vault & Awareness: Maintains user scan history, downloadable OpenPDF reports, and a Scam Intelligence Center.
Pure Java Backend

Engineered 100% in Java with Spring Boot 3, Hibernate JPA, and OpenPDF. Zero Python scripts, zero external microservices. High throughput, type-safe reliability.

Non-Executing Passive URL Parsing

Inspects link structures safely with java.net.URI and java.net.IDN. Unmasks shorteners, flags Punycode, IP hosts, and deceptive paths without visiting dangerous destinations.

User Privacy & Auditing

Protected by Spring Security with BCrypt password hashing. Each user maintains a private scan vault, personal analytics dashboard, and exportable incident records.

Algorithmic Heuristic Notice

The ScamLens Risk Score (0–100) is a heuristic risk indicator, not a mathematical certainty or legal proof that a communication is fraudulent. A low score does not guarantee absolute safety, and a high score does not prove criminal intent. Users must exercise independent verification and never disclose sensitive authentication credentials over unverified channels.
